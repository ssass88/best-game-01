**CYBER BLADE: NEON OVERDRIVE** is a high-octane neon retro-arcade space shooter built for make.fun's **best-game-01** bounty ($1,000 USDC).
Built with 100% offline static canvas ES modules and a custom Web Audio API procedural sound engine — zero external libraries, zero network requests.

## Gameplay & Features

- **Pure Offline Canvas & CRT Glow**: High-frame-rate glowing neon ships, perspective synthwave grid, starfield background, and shockwave particle system.
- **Diverse Enemy Armada**: 4 distinct hostile classes with tailored attack patterns: agile Scouts, rapid-firing Interceptors, shielded Cruisers, and heavy Dreadnought bosses.
- **Tactical Combat Systems**: Twin forward plasma lasers, triple spread upgrades, dynamic regenerating energy shield, and full-screen EMP Shockwave Nova.
- **Deep Scoring Mechanics**: Combo multiplier chain (up to x8), accuracy tracking, and end-of-run combat evaluation (Rank S+ rating).
- **Procedural Web Audio Engine**: Zero-asset procedural audio synthesizing laser discharges, pulse explosions, EMP bursts, and shield powerup sweeps.

## Play Locally

```sh
node serve.ts
```
Then open `http://localhost:8080` in your desktop web browser.

## Controls

- **Move**: `W`, `A`, `S`, `D` or Arrow Keys
- **Fire**: Left Click or `J` (Hold for rapid fire)
- **EMP Nova**: `Space` or `Shift`
